# Qwen3-TTS LoRA — русский Google Colab

Этот Colab превращает обучение Qwen3-TTS LoRA в поток, похожий на Applio/RVC:

1. Первая ячейка ставит два изолированных окружения: Qwen3-TTS и Qwen3-ASR.
2. Вторая ячейка подключает Google Drive и направляет туда проекты, checkpoint и Hugging Face cache.
3. Третья ячейка запускает русский Gradio и остаётся работающей. stdout/stderr не перехватываются, поэтому вывод не исчезает.
4. В интерфейсе задаются имя проекта и папка с длинными записями.
5. Подготовка датасета сама режет записи по паузам, приводит их к 24 кГц mono и расшифровывает русскую речь Qwen3-ASR-0.6B.
6. LoRA обучается на Qwen3-TTS Base. На T4 по умолчанию предлагается 0.6B.
7. После каждой эпохи адаптер и состояние optimizer копируются на Google Drive. Кнопка продолжения ищет последний полностью сохранённый checkpoint.

## Почему два Python-окружения

`qwen-tts==0.1.1` фиксирует `transformers==4.57.3`, а `qwen-asr==0.0.6` фиксирует `transformers==4.57.6`. Разделение окружений исключает конфликт зависимостей.

## Прогресс

Во время нарезки, распознавания и обучения используется `tqdm`: одна строка перерисовывается на месте. Новые строки печатаются только для важных событий, например завершения эпохи и сохранения checkpoint.

## Заимствованный код

LoRA-часть `train_lora.py` адаптирована из MIT-проекта Alexandria Audiobook Generator (Copyright 2026 Finrandojin) и переработана для Colab, T4, checkpoint/resume и компактного прогресса. Qwen3-TTS и Qwen3-ASR используются через официальные открытые пакеты Qwen.

## CI

GitHub Actions запускает smoke suite внутри официального Google Colab CPU runtime image. CI:

- устанавливает оба окружения с нуля;
- импортирует Qwen3-TTS, tokenizer, PEFT и Qwen3-ASR;
- строит русский Gradio;
- через Playwright нажимает основные кнопки и проверяет, что callback доходят до Python;
- проверяет launcher с живым stdout;
- не скачивает многогигабайтные веса и не запускает обучение.
