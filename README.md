# Audio Restoration Colab

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/egor125552/audio-restoration-colab/blob/main/notebooks/Audio_Restoration_RU.ipynb)

Русский интерфейс для очистки шума и нейросетевой дорисовки верхних частот.
Google Drive и ключи API не нужны.

## Seed-VC

[![Открыть Seed-VC в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/egor125552/audio-restoration-colab/blob/main/notebooks/Seed_VC_RU.ipynb)

Отдельный блокнот запускает Seed-VC V2 для преобразования разговорного голоса.
Он ставит закреплённый upstream Seed-VC в Python 3.10 и перед запуском проверяет
реальные импорты и создание интерфейса. Для него выбери T4 GPU.

## Как запустить

1. Нажми кнопку «Открыть в Google Colab» выше.
2. В Colab открой меню «Среда выполнения», затем «Сменить среду выполнения».
3. Выбери аппаратный ускоритель T4 GPU.
4. Выполни ячейки сверху вниз. Первые две устанавливают только интерфейс.
5. В последней ячейке появится временная ссылка Gradio. Открой её.
6. Загрузи аудио, выбери модель и формат, затем начни обработку.

Google Colab может отключить бесплатную сессию. После отключения модели придётся
скачать заново. Пока временная ссылка Gradio работает, открыть её может любой,
кому ты её отправишь.

## Пять режимов

| Режим | Для чего | Важное ограничение |
|---|---|---|
| DeNoise, обычная | Убрать шум, сохранить больше полезного звука | Не дорисовывает частоты |
| DeNoise, агрессивная | Очень шумные записи | Может задеть тихие инструменты |
| LavaSR, маленькая | Речь, звонки, телефонные записи | Пока не обучена для музыки |
| FlashSR, средняя | Музыка, речь, обычные звуки | Скачивает около 3,2 ГБ весов |
| AudioSR, большая | Тяжёлая дорисовка музыки и звуков | Медленная, чувствительна к MP3-срезу |

Модель скачивается только при первом запуске выбранного режима. DeNoise
возвращает очищенный звук и выделенный шум. Режимы дорисовки возвращают один
восстановленный файл.

## Форматы

- как у исходного файла;
- MP3 320 кбит/с;
- WAV без сжатия.

Каждый результат можно прослушать и скачать отдельно. Также создаётся общий
ZIP-архив.

## Что проект не обещает

Удалённые частоты невозможно вычислить точно по оставшемуся файлу. FlashSR и
AudioSR создают правдоподобное продолжение спектра. Иногда оно звучит лучше,
иногда добавляет искусственный шорох или металлические призвуки. Поэтому
оригинал всегда нужно сравнивать с результатом на слух.

Для минусовок после удаления вокала разумный порядок такой:

1. Обычная DeNoise, только если слышен шум или вокальный след.
2. FlashSR с включённой подготовкой частотного среза.
3. AudioSR — только если FlashSR недостаточно хороша и есть время ждать.

## Разработка и проверки

На компьютере Егора зависимости не устанавливаются. GitHub Actions выполняет:

- проверку кода;
- 27 быстрых тестов логики;
- запуск Gradio без тяжёлых моделей;
- открытие страницы в Chromium и проверку русских элементов интерфейса.

Seed-VC дополнительно проверяется в чистом официальном Docker-образе Google
Colab: полная установка зависимостей, `pip check`, реальные импорты V1/V2 и
Chromium-проверка загрузок WAV, настроек, Submit и Clear с вызовом Python-бэкенда.

Команды для отдельной среды разработчика:

```bash
uv sync --all-groups
uv run ruff check .
uv run pytest
uv run audio-restoration-colab --demo
```

Полные требования записаны в [спецификации](docs/spec.md).
