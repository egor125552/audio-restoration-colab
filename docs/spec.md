# Спецификация: Audio Restoration Colab

## Цель

Сделать публичный репозиторий с одним Google Colab-блокнотом и русским
Gradio-интерфейсом. Пользователь загружает аудиофайл, выбирает одну модель,
меняет только относящиеся к ней настройки, запускает обработку и скачивает
отдельные результаты или ZIP-архив.

Google Drive, регистрация в сторонних сервисах и ключи API не нужны.

## Модели первой версии

1. **DeNoise, обычная** — `denoise_mel_band_roformer_aufr33_sdr_27.9959.ckpt`.
   Возвращает очищенный звук и выделенный шум.
2. **DeNoise, агрессивная** —
   `denoise_mel_band_roformer_aufr33_aggr_sdr_27.9768.ckpt`.
   Сильнее убирает шум, но чаще затрагивает полезный звук.
3. **LavaSR, маленькая** — около 50 МБ. Быстрая модель для речи и телефонных
   записей. Для музыки не рекомендуется: автор ещё не выпустил музыкальное
   обучение.
4. **FlashSR, средняя** — однопроходная модель для речи, музыки и обычных
   звуков. Выход 48 кГц.
5. **AudioSR, большая** — тяжёлая многопроходная модель для речи, музыки и
   обычных звуков. Выход 48 кГц, обработка заметно медленнее.

Модели и их отдельные среды скачиваются лениво: только при первом запуске
выбранного режима. Они не хранятся в Git-репозитории.

## Интерфейс

- Весь видимый текст на русском языке.
- Один загружаемый аудиофайл.
- Выбор модели с коротким честным описанием, размером, назначением и
  предупреждениями.
- Панель настроек меняется при выборе модели.
- Настройки каждой модели сохраняются отдельно в хранилище браузера.
- Общий формат результата:
  - как у исходного файла;
  - MP3 320 кбит/с;
  - WAV без сжатия.
- Кнопка запуска, понятный текущий статус и сообщение об ошибке без длинного
  технического лога.
- Предпрослушивание результатов.
- Скачивание каждого результата отдельно.
- Скачивание ZIP со всеми результатами текущего запуска.
- Интерфейс должен быть пригоден для клавиатуры и экранного диктора.

## Индивидуальные настройки

- DeNoise: качество/скорость обработки и размер фрагмента.
- LavaSR: исходная полоса частот, удаление шума, длинный файл.
- FlashSR: предварительно ограничить верхние частоты.
- AudioSR: режим «обычный звук» или «речь», число шагов, сила обработки,
  случайное зерно и предварительный фильтр для MP3/нестандартного среза.

Опасные или бессмысленные значения не показываются. Значения по умолчанию
должны помещаться в Tesla T4 с 16 ГБ видеопамяти.

## Технологии и версии

- Python 3.11 для интерфейса.
- Gradio 6.21.0.
- `audio-separator[gpu]` 0.44.5 для моделей DeNoise.
- LavaSR из официального репозитория, зафиксированный на конкретной версии
  исходного кода.
- FlashSR из репозитория с кодом и весами LAION; в интерфейсе будет явно
  указано, что это удобная перепаковка исходной работы.
- AudioSR 0.0.7 из официального репозитория.
- FFmpeg для преобразования WAV/MP3 и сохранения исходного формата.
- `uv` создаёт отдельные среды моделей внутри Colab, чтобы несовместимые
  зависимости не ломали друг друга.

## Команды

```bash
# Установка только интерфейса и тестов
uv sync --all-groups

# Проверки
uv run ruff check .
uv run pytest

# Локальный запуск без скачивания моделей
uv run audio-restoration-colab --demo
```

В Google Colab эти команды выполняются готовыми ячейками. На компьютере Егора
зависимости не устанавливаются.

## Стиль кода

Логика модели отделена от интерфейса. Публичные функции имеют типы и короткие
понятные имена.

```python
def output_extension(choice: str, source: Path) -> str:
    if choice == "wav":
        return ".wav"
    if choice == "mp3":
        return ".mp3"
    return source.suffix.lower()
```

## Проверки

- Модульные тесты проверяют каталог моделей, индивидуальные настройки,
  команды запуска, безопасные имена файлов, форматирование и ZIP.
- Интеграционный тест запускает Gradio в демонстрационном режиме без весов.
- Браузерный тест открывает страницу в GitHub Actions и проверяет заголовок,
  выбор модели, загрузку файла и доступные названия элементов.
- Тяжёлые веса в GitHub Actions не скачиваются.

## Границы

### Всегда

- Проверять тип и существование входного файла.
- Создавать отдельную папку для каждого запуска.
- Передавать команды списком аргументов, без выполнения пользовательской
  строки через оболочку.
- Удалять временные результаты старых запусков.
- Показывать ограничения каждой модели до запуска.

### Сначала согласовать

- Добавление новых тяжёлых моделей.
- Переход к платным GPU или внешним API.
- Публикацию пользовательских аудиофайлов.

### Никогда

- Не коммитить веса, аудиофайлы, токены и временные результаты.
- Не подключать Google Drive.
- Не обещать точное восстановление исходных частот: модели генерируют
  правдоподобное продолжение спектра, а не возвращают удалённые данные.

## Критерии готовности

1. Репозиторий открывается кнопкой «Открыть в Colab».
2. После запуска ячеек появляется русский Gradio-интерфейс.
3. Все пять режимов видны, а их настройки меняются отдельно.
4. Выбранная модель устанавливается и скачивается только при первом запуске.
5. Результаты можно прослушать и скачать отдельно или одним ZIP.
6. Форматы «как исходный», MP3 320 и WAV работают.
7. GitHub Actions успешно выполняет статические, модульные и браузерные
   проверки без загрузки тяжёлых моделей.

## Принятые допущения

- Репозиторий называется `egor125552/audio-restoration-colab` и будет
  публичным.
- Первая версия обрабатывает один файл за запуск.
- 53-стемовая модель не входит в первую версию: она не восстанавливает
  частоты и делает бесплатную Tesla T4 нестабильной.
